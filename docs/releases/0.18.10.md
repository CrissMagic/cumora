# Cumora 0.18.10 · Windows

## 智能体岗位模板

- 提供 21 个科技公司常用岗位，覆盖规划协作、研发质量、产品设计、研究数据和运营支持。
- 支持分类查找和搜索。套用后自动填入名称、职责与提示词，选择执行电脑和引擎即可创建。
- 支持展开自定义角色、模型和头像设置；现有智能体的人设保持原有内容。
- 团队继续采用扁平协作，未引入组织树或上下级权限。

## Windows 体验

- 通用安装包不内置个人服务域名。首次启动填写并检查自己的服务地址，保存在本机；登录页支持切换，切换时清除旧登录状态。已有保存地址继续沿用。
- 通知区域采用彩色品牌图标，在深色和浅色任务栏上更清楚，保留未读标记。
- 桌面安装包排除 Capacitor / Android 原生工程依赖及其编译缓存，减少安装和卸载中的长路径风险。

## 软件内更新

- Windows 安装版更新源改为 CrissMagic/cumora 的 GitHub Releases。
- 启动时及每 30 分钟检查，也可从“我 → 关于 → 检查更新”手动触发。
- 用户确认下载与重启安装；支持进度展示和 SHA-512 校验，错误会明确显示。

## 安装说明

- 仅适用于 Windows x64；Android 仍通过原有 APK 方式安装。
- 此前没有配置更新源的试用安装包，需要手动安装一次本版本，才能接收后续软件内更新。
- 覆盖旧包时若出现“Cumora 无法关闭”，请参阅仓库 docs/WINDOWS_INSTALLATION.md 的短临时路径方法；首次覆盖旧卸载器的完整升级仍需实际环境验收。
- 当前未配置 Windows 发布者签名证书；GitHub 更新链路使用下载完整性校验，不能替代发布者代码签名。
